## 📌 Overview

**MicroTask** is a full-stack micro-tasking platform where users can earn money by completing small online tasks. The platform supports three different user roles — **Worker**, **Buyer**, and **Admin** — each with dedicated features and responsibilities.

Inspired by platforms like **Picoworkers** and **Clickworker**, this application provides secure authentication, task management, coin-based transactions, payment integration, and a seamless user experience.

---

## 🚀 Key Features

* ✅ Role-Based Authentication System (Worker, Buyer, Admin)
* ✅ Firebase Authentication with JWT Authorization
* ✅ Protected Routes & Secure API Access
* ✅ Workers can complete tasks and earn coins
* ✅ Buyers can create and manage tasks
* ✅ Admin can manage users, tasks, and withdrawals
* ✅ Real-time Notification System
* ✅ Coin-Based Earning & Withdrawal Mechanism
* ✅ Stripe Payment Integration
* ✅ Task Filtering & Sorting
* ✅ Image Upload Support via imgBB
* ✅ Pagination for Better Performance
* ✅ Responsive & Modern User Interface
* ✅ Interactive Homepage with Swiper Slider
* ✅ Dynamic Dashboard Based on User Role
* ✅ Withdrawal Approval System
* ✅ Task Approval/Rejection Workflow

## 👨‍💻 User Roles & Functionalities

### 🧑‍🔧 Worker

* View available tasks
* Submit completed tasks for review
* Earn coins for approved submissions
* Withdraw earnings
* Receive approval/rejection notifications

### 🧑‍💼 Buyer

* Create and manage tasks
* Review worker submissions
* Approve or reject submissions
* Purchase coins using Stripe
* Track payment history

### 🛠️ Admin

* Manage all users and roles
* Monitor platform statistics
* Approve withdrawal requests
* Remove tasks or users when necessary
* Maintain platform integrity

## 📊 Business Logic

### 💰 Coin Purchase

* Buyer purchases **10 Coins = $1**

### 💸 Withdrawal System

* Worker withdraws **20 Coins = $1**

### 🧠 Platform Revenue Model

The platform generates profit from the difference between the coin purchase rate and withdrawal rate.
